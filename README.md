# Dylan Wang — Portfolio 📝

An interactive, handwritten notebook-desk portfolio website showcasing computer science projects, technical experience, and interactive doodles.

Built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

---

## ✨ Features

- **Interactive Pencil & Eraser**: Freehand scribble and draw anywhere on the screen with a synchronized graphite pencil lead cursor, swap to a pink eraser, or clear drawings with the animated sticky note.
- **Handwritten Notebook Paper Aesthetic**: Dual-sheet lined notebook paper complete with red margins, blue ruling lines, hole punches, washi tape, and pencil crossout animations on link clicks.
- **Hand-Drawn Doodles**: Custom sketches seamlessly integrated with realistic blend modes (Purdue 'P', Graduation '28, Chelsea FC crest, Washington Commanders 'W', Tic-Tac-Toe, and Cat doodle).
- **Project Highlights**:
  - **[Beyond the Stats](https://beyondthestatsapp.com/)**: Soccer predictive ML model and SwiftUI/web app forecasting match results with 63% accuracy across 10,000+ matches.
  - **[Draft It! Soccer Game](https://apps.apple.com/us/app/draft-it-38-0-draft/id6797634589)**: Draft & season simulation iOS game available on the App Store.
  - **[Boilermates](https://github.com/DYitaoW/BoilermatesFinalCopy)**: Social networking app with a custom client/server socket architecture.
- **Responsive & Accessible**: Fully responsive layout across desktop, tablet, and mobile with touch drawing support and `prefers-reduced-motion` compliance.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Custom CSS Grid/Variables
- **Typography**: Google Fonts (*Caveat* & *Patrick Hand*)
- **Build Tool**: Vite 8
- **Platform**: Figma Make / Web

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- pnpm / npm

### Installation & Run

```bash
# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```
